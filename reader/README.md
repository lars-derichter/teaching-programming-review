# Reader: teaching programming to beginners

A curated collection of fifteen key publications from computing education
research, with introductions, for students learning how to teach programming
to beginners in an associate degree (graduaat) programme.

## How to use this reader

Each theme file contains an introduction to the theme and, per article, three
things: why the article was selected, how to read it (what to study closely
and what to skim), and a small set of guiding questions. Read the introduction
before the article and return to the guiding questions afterwards — they are
written to be usable directly as seminar discussion questions or as prompts
for a reading journal.

Read theme 1 (Brown & Wilson) first: it is the ten-minute overview that every
later article deepens. The remaining themes build on each other in order, but
each can also be read independently.

## Provenance and status

The selection is based on the literature review in this repository
([literature-review-teaching-programming-beginners.md](../literature-review-teaching-programming-beginners.md)).
Every article was read in full before inclusion; the selection process and
the keep-or-set-aside decisions are documented in
[selection-log.md](selection-log.md). The introductions summarise
and interpret the articles for teaching purposes; before citing any claim in
formal academic work, verify it against the original publication.

The PDFs were obtained through open access channels and the Open Universiteit
library. They are bundled here for use within an educational context; obtain
the appropriate permissions before wider distribution.
